# Guess Number Game

## 프로젝트 소개

C#의 기본 문법을 익히기 위해 만든 콘솔 숫자 맞히기 게임입니다.
컴퓨터가 정한 1~100 사이의 정수를 UP/DOWN 힌트를 참고해 맞힙니다.
정답을 맞히면 시도 횟수를 확인하고 새 게임을 시작할 수 있습니다.

## 실행 방법

.NET 10 SDK가 필요합니다.

1. 저장소를 내려받고 해당 폴더로 이동합니다.

   ```bash
   git clone https://github.com/yxrxm/Csharp_subjects.git
   cd Csharp_subjects
   ```

2. 게임을 실행합니다.

   ```bash
   dotnet run --project GuessNumberGame
   ```

3. 메뉴에서 `1`을 입력하면 게임이 시작되고, `2`를 입력하면 종료됩니다.
4. 1~100 사이의 정수를 입력하고 Enter를 누릅니다.
   - 입력한 숫자가 정답보다 크면 `DOWN!`이 출력됩니다.
   - 입력한 숫자가 정답보다 작으면 `UP!`이 출력됩니다.
   - 정답을 맞히면 시도 횟수가 출력됩니다.
5. 재시작 질문에 `Y`를 입력하면 새 게임을 시작하고, `N`을 입력하면 종료합니다. 소문자와 앞뒤 공백도 허용합니다.

잘못된 값을 입력하면 안내 메시지가 나오며 다시 입력할 수 있습니다.

## 구현 기능

- 게임 시작 및 종료 메뉴와 메뉴 입력 검증
- `Random.Next(1, 101)`을 이용한 1~100 사이의 정답 생성
- 입력한 숫자와 정답을 비교한 UP/DOWN 힌트 제공
- `int.TryParse()`를 이용한 정수 입력 검증과 1~100 범위 검사
- 올바른 범위의 정수만 시도 횟수에 포함하고, 정답을 맞힌 시도까지 집계
- 재시작 시 새로운 정답 생성 및 시도 횟수 초기화
- 재시작 응답의 대소문자와 앞뒤 공백 처리
- Y/N 이외의 재시작 응답에 대한 재입력 안내
- 입력 스트림이 끝나 `Console.ReadLine()`이 null을 반환하면 프로그램 종료

## 배운 점

- `Main()`이 프로그램의 실행 시작점이라는 것을 배웠습니다.
- `Console.WriteLine()`과 `Console.Write()`로 내용을 출력하고, `Console.ReadLine()`으로 문자열을 입력받았습니다.
- `int.Parse()`를 사용한 초기 코드에서 `int.TryParse()`로 개선하며, 변환 실패를 확인하고 다시 입력받는 방법을 익혔습니다.
- `out int`로 변환 결과를 받고, 앞에 붙이는 `!`로 성공 여부를 반전시켜 실패 조건을 검사했습니다.
- `string?`가 null을 허용하는 참조 형식 표기라는 것과, null 입력을 명시적으로 처리하는 방법을 배웠습니다.
- `Random.Next()`는 최솟값을 포함하고 최댓값은 포함하지 않는다는 것을 배웠습니다.
- `if`, `else if`, `else`와 논리 연산자 `||`로 조건을 검사했습니다.
- 반복문을 중첩해 게임 한 판, 숫자 추측, 재시작 질문의 반복 범위를 구분했습니다.
- `continue`는 다음 반복으로 넘어가고, `break`는 가장 가까운 반복문을 끝내며, `return`은 현재 메서드를 끝낸다는 차이를 익혔습니다.
- 입력 검증 뒤에 시도 횟수를 증가시켜 잘못된 입력을 횟수에서 제외했습니다.
- `Trim()`과 `ToUpperInvariant()`로 응답을 정리하고, 문자열 보간으로 시도 횟수를 출력했습니다.
