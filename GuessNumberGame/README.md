# Guess Number Game

## 프로젝트 소개

C#의 기본 문법을 익히기 위해 만든 콘솔 숫자 맞히기 게임입니다.
컴퓨터가 정한 1~100 사이의 정수를 입력으로 맞히며, UP/DOWN 힌트를 통해 정답을 찾아갑니다.

## 실행 방법

.NET 10 SDK가 필요합니다.

1. 저장소를 내려받고 해당 폴더로 이동합니다.

   ```bash
   git clone https://github.com/yxrxm/Csharp_subjects.git
   cd Csharp_subjects
   ```

2. 게임 프로젝트를 실행합니다.

   ```bash
   dotnet run --project GuessNumberGame
   ```

3. 메뉴에서 `1`을 입력하면 게임이 시작되고, `2`를 입력하면 종료됩니다.
4. 숫자를 입력하고 Enter를 누릅니다. 힌트를 참고해 정답을 맞힙니다.
5. 정답을 맞힌 뒤 `Y` 또는 `y`를 입력하면 새 게임을 시작하고, `N` 또는 `n`을 입력하면 종료합니다.

현재 메뉴와 추측 입력은 정수로 입력해야 합니다. 문자나 빈 입력에 대한 예외 처리는 아직 구현하지 않았습니다.

## 구현 기능

- 게임 시작 및 종료 메뉴
- `Random.Next(1, 101)`을 이용한 1~100 사이의 정답 생성
- 입력한 숫자가 정답보다 크면 `DOWN!`, 작으면 `UP!` 출력
- 정답을 맞히면 정답 메시지와 시도 횟수 출력
- 게임 재시작 시 정답을 새로 생성하고 시도 횟수를 초기화
- 재시작 입력의 대소문자 허용 (`Y/y`, `N/n`)

현재 1~100 범위 밖의 정수도 추측으로 처리하며 시도 횟수에 포함됩니다. 재시작 질문에 Y/N 이외의 값을 입력하면 안내 메시지를 출력하고 종료합니다.

## 배운 점

- `Main()`이 프로그램의 실행 시작점이라는 것을 배웠습니다.
- `Console.WriteLine()`과 `Console.Write()`로 콘솔에 내용을 출력하고, `Console.ReadLine()`으로 입력을 받았습니다.
- `int.Parse()`로 입력 문자열을 정수로 변환했습니다.
- `string?`는 null을 허용하는 참조 형식 표기이며, 식 뒤의 `!`는 null 관련 경고를 억제할 뿐 오류를 방지하지 않는다는 것을 배웠습니다.
- `Random.Next()`의 최솟값은 포함되고 최댓값은 포함되지 않는다는 것을 배웠습니다.
- `if`, `else if`, `else`로 입력값과 정답을 비교했습니다.
- 이중 `while`문으로 한 판의 추측 반복과 게임 재시작을 구현했습니다.
- `break`는 가장 가까운 반복문을 끝내고, `return`은 현재 메서드를 끝낸다는 차이를 익혔습니다.

앞으로는 `int.TryParse()`를 활용한 입력 검증과 1~100 범위 검사를 추가해 보고 싶습니다.
