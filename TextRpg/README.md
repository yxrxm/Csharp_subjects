
# C# Week 2 — Text RPG

## 구현한 기능

- Player / Enemy 간 턴제 전투 및 HP, 공격력 기반 공격 시스템
- 공격 / 상태 확인 메뉴와 `int.TryParse`를 이용한 잘못된 입력 처리
- Slime, Devil, Professor 세 종류의 적 중 랜덤으로 상대 선택
- 플레이어 HP를 유지하며 연속 전투 진행, 쓰러뜨린 적은 전투에서 제외
- 플레이어 패배 또는 모든 적 처치 시 게임 종료 및 결과 출력
- `Character` 상속으로 공통 기능을 재사용하고, `List<Enemy>`로 적 목록 관리

## 클래스 구조

- `Character`: 이름, HP, 공격력을 저장하고 공격 및 상태 출력 기능 제공
- `Player`: `Character`를 상속받는 플레이어 클래스
- `Enemy`: `Character`를 상속받으며, 생성된 적을 공용 리스트에 등록
- `Program`: 플레이어와 적 생성, 랜덤 적 선택, 메뉴 및 연속 전투 흐름 관리

## 배운 점 / 막힌 점

- `List`는 선언 후 초기화해야 사용할 수 있으며, `Count`와 랜덤 인덱스로 적을 선택할 수 있다는 것을 배웠다.
- `int.TryParse`로 숫자 변환 여부를 확인하고, 메뉴 범위를 따로 검사하는 방법을 익혔다.
- 개별 전투의 처치·패배 문구와 게임 전체의 종료 문구를 구분해 출력하도록 정리했다.
